# cs504-team-project

# Important Assets

1. Requirements.txt: Contains all the dependencies required for the project. Use `pip install -r requirements.txt` to install them.

2. .env: Needed to be created in the root directory of the project. Contained variables are used to configure the application. Usage of them can be found in the `config.py` file. 

3. `app/main/templates/`: Contains the HTML templates used for rendering web pages and emails.

4. `TP/Documents/refactoring`: Explain the process of refactoring the codebase, from naive authentication implementation to good practice Flask development. It also includes the reasoning behind the changes made and the benefits of refactoring.
